About this mock

Walkthrough with the code at the centre. The real code of the GET /source flow, so the file view has real lines to hold.

  • Three panes, one story. Sequence at the left to know where you are, the file in the middle to read, the words of the step at the right. The code is no longer a 320px excerpt inside a card.
  • The whole file, scrolled to the step. Tabs are the files the walk touches, in the order it reaches them. The span is the one amber thing; the rest of the file reads quietly.
  • Click a method, the walk follows. Dotted words are methods the walkthrough has a step for; the numbered chips in the gutter are steps that start on that line. Either one moves the whole walkthrough, diagram and card included.
  • Back, like an IDE. After a jump a chip offers the step you left.
  • Motion. Keyboard steps are instant; scroll and wash ease only for a click or while playing. Reduced motion keeps the jump.

Try: click project_folder in the service, a gutter chip, a message on the left, ← →, Space.
