About this mock

One section, two doors. Work and Project › Tasks are the same component. The scope is its only input: all projects groups by project, one project drops the group header and adds the adherence strip.

One create path. The quick-task textarea and the New task button become one composer. The key starts a quick task; its menu opens the full task dialog (key T) with the text as the title. With no project scope, a chip picks the project.

Delete from the list. A trash key ends every row, shown on hover or focus, with the same confirm the task page uses. Fourteen of the Rekall vR tasks are quick tasks that stay In progress, so clearing them is a real job.

No sideways shift. The page scroller reserves its scrollbar gutter, so a short tab (Blueprint) and a long one (Tasks) keep one left edge. Click Tasks and Blueprint in the Project scene.

Data is real: Rekall vR (173 tasks, 10 open, 266 of 278 steps accepted first time), with HyperCV beside it. The all-projects list shows 2 of its 12 groups.
